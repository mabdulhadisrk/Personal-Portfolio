# Personal Portfolio - Muhammad Abdul Hadi
This project is a personal website I created for myself.
# Languages
I used HTML and CSS to structure and style and make it into this beautiful, attracting website ( unlike others ).
# Reason for making
I created this website for professional reasons. I wanted to show myself and my talent through which I may get hired for internships and jobs in future.

It features 4 sections, each of different category. smooth scrolling with a hrefs at the top. Link to my github at the end. Beautiful attractive website. beautiful css animations such as background animation, live circle pulses ( top right ) and smooth underline animation for Github link and for "MA".
